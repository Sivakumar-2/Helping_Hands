# Helping Hands 🩸

Helping Hands is a **Blood Donation Management System** developed using Django.
The platform connects **blood donors with people who need blood**, helping manage donations efficiently.

---

## 📌 Features

* User Registration and Login
* Blood Donor Registration
* Search Donors by Blood Group
* Blood Request System
* Donor Information Management
* **Admin Dashboard for managing users and donors**
* Simple and user-friendly interface

---

## 🔑 Admin Panel

The project includes a **Django Admin Panel** where administrators can manage system data easily.

Admin can:

* Add / Edit / Delete donor records
* Manage registered users
* Monitor blood requests
* Update database information

Admin panel URL:

```id="rmb7iq"
http://127.0.0.1:8000/admin/
```

## ⚙️ Installation & Setup

### Clone the repository

```id="du9z8t"
git clone https://github.com/Sivakumar-2/Helping_Hands.git
```

### Go to project folder

```id="68mm7r"
cd Helping_Hands
```

### Install dependencies

```id="myt6rb"
pip install -r requirements.txt
```

### Run the development server

```id="8xx0fc"
python manage.py runserver
```

### Open in browser

```id="3bhvho"
http://127.0.0.1:8000/
```
